# PC Care

Quiet background cleaner for Windows. Runs from the tray, works only when you are away and the CPU is quiet, never shows popups unless you turn them on.

Jobs: temp/junk files, browser caches (cache only), old Recycle Bin items, freeing RAM from big background programs, DNS/thumbnail caches, health check. Settings window: per-job schedule, aggressiveness, speed tweaks (reversible), repair tools (DISM/SFC, disk scan, RAM test, deep clean as admin), and a log.

It never deletes your documents, desktop or downloads, and never force-kills programs.
